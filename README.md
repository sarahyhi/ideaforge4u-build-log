# IdeaForge

From spark to structure in 20 minutes.

IdeaForge helps solo founders and product managers turn a raw idea into a structured, buildable project outline. Capture your idea without interruption, let AI challenge it with pointed questions that surface assumptions and risks, then generate a clean document covering the problem, target users, solution, and next steps.

Live preview: https://ideaforge4u.lovable.app

Build log: [BUILD_LOG.md](https://github.com/sarahyhi/ideaforge4u-build-log/blob/main/BUILD_LOG.md)

## How it works

Three modes, one flow:

1. **Capture** — write freely, no AI, no distractions.
2. **Expand** — AI asks hard questions to challenge and clarify your thinking.
3. **Structure** — generates a shareable document: problem, users, solution, key ideas.

## Built with

- **Miro** — idea mapping and planning
- **Lovable** — builds, hosts, and deploys the app
- **Claude** — feature and UI planning, drafts specs for Lovable to implement

## Status

Prototype. Core functionality is built but not yet backed by persistent storage. Next: adding a database and login so users can actually save their ideas.
